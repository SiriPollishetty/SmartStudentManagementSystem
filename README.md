# Smart Student Management System

## Project Description

Smart Student Management System is a console-based Java application developed to manage student information.

The system allows users to add, display, search, and generate reports for different types of students such as Day Scholars, Hostellers, and Sports Students.

This mini project is developed using Object-Oriented Programming concepts from Java Unit 1 and Unit 2.

---

## Features

- Add Day Scholar
- Add Hosteller
- Add Sports Student
- Display all students
- Search student by Student ID
- Calculate average marks
- Calculate student grade
- Check attendance status
- Calculate student fees
- Generate student reports

## Student Types

The system supports three types of students:

1. Day Scholar
2. Hosteller
3. Sports Student

All these classes inherit from the abstract Student class.

---

## How to Run

1. Open the project in Visual Studio Code.
2. Make sure Java is installed on your computer.
3. Open the Main.java file.
4. Run the Main.java file.
5. Select an option from the menu.
6. Enter the required student details.
